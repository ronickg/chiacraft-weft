# Nights by the moon (Ronald, 11-04: a full moon lights the night, no moon is dark, torches light
# the way). The moon lags the day by its phase: up all night when full, only by day when new. Each
# case with nothing in hand, then a torch. Seed 1, --view 12, 1280x720, --shader-pack chiacraft, a
# fresh world. Creative on a grass floor high in the open (x 40 y 200 z 40), mobs off.
# Days: `/time set` only moves forward to the next such time of day, it never sets the day. A new
# world starts on day 7 (phase 7); day 8 is full, day 11 a waning crescent, day 12 new, day 16 full.
# So each day forward is a `time set 6000` (its noon) then `time set 18000` (its midnight). Yaw 0 faces -z; the
# moon sets in the west (yaw 90).
loaded
idle
chat /rule core:mob_spawning 0
chat /weather clear 99999
chat /tk mode creative
chat /time set 6000
chat /tp 40 205 52
loaded
idle
wait 6
chat /tk fill 26 199 30 54 199 64 grass
chat /tk fill 36 200 44 36 203 44 oak_log
chat /tk fill 44 200 43 45 201 43 cobblestone
chat /tk fill 40 200 41 40 200 41 mossy_cobblestone
chat /tk fill 30 200 38 30 202 38 spruce_log
chat /tp 40 200.2 50
wait 3
chat /tk put me 0 stick
# 1. Full moon high (day 8, midnight).
chat /time set 18000
chat /time set 6000
chat /time set 18000
