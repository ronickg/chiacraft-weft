# Creature-crowd bench (reports/Creature AI.md, part 3, step 0). Seed 1, spectator, standing still,
# mobs off. A thousand animals resting (54-70 blocks out, past core:entity_activation_distance 48),
# then 100, 250, 500 and 1000 active ones within 6-40 blocks, a 20 s bench at each; then the same
# 1000 hungry and thirsty (foraging, drinking, hunting). Read per bench: the BENCH line's
# 'server avg/max', 'mods per tick: animals' and 'entities N', and the ANIMAL_GOALS line after it
# (the animals mod's per-goal timer, `/animalprof`). Mix: deer, reindeer, hares, mice, foxes,
# wolves, ravens. Run as a bench (alone): t2q.py bench <id> <TREE> <this> --limit 420 -- --seed 1
loaded
idle
chat /rule core:mob_spawning 0
chat /weather clear 99999
chat /tk mode spectator
chat /tk time 6000
wait 8
chat /animalprof count
chat /animalprof on
bench 20 empty
chat /animalprof dump
