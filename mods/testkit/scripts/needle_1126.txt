# The bone needle (11-26, first.rs BONE_NEEDLE, vitals::first::NEEDLE_USES, clothing.rs
# with_needle): a bone splinter ground on a rock (the rock kept) makes a needle; every garment and
# cloak is sewn with one, wearing it by the string it takes. Seed 1, a fresh world.
# Part 1, the recipes (/tk craft answers the grid's output):
#   - splinter + rock (1 x 2) -> base:bone_needle 1
#   - a hide hat: leather / string / needle (1 x 3) -> base:hide_hat 1; leather / string (1 x 2),
#     no needle -> nothing (air or none 0)
#   - a wool cloak: wool string wool / . wool . / . needle . (3 x 3) -> base:wool_cloak 1; the same
#     without the needle row (3 x 2) -> nothing
#   - linen coat: cloth string cloth / cloth string cloth / . needle . -> base:linen_coat 1
# Part 2, the hint: in survival, leather given with no needle in the bag: the hint "To sew
#   clothes you need a needle..." shows (shot fp_needle_hint).
# Read: every /tk craft reply, the shot, run.log "panicked"/"ERROR" (none).

chat /tk craft 1 2 base:leather base:string

chat /tk craft 3 2 base:wool base:string base:wool air base:wool air
chat /tk craft 3 3 base:cloth base:string base:cloth base:cloth base:string base:cloth air base:bone_needle air
