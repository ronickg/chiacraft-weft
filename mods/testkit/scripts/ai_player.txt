# The player's own sounds and the sounds of using things (mods/base/src/player_sounds.rs,
# notes/crew/plans/ai-sound.md batch 4). A script can't hear: read run.log's "sound files:" line
# and `/sounds check` reply (no events missing files) and every `/sounds recent` reply after each
# part. Expect, part by part (base:player.* and base:use.*):
#  hurt: player.hurt | fall: player.fall (+ hurt) | short drop: player.land | water: player.splash,
#  player.swim, player.drown (after ~15 s under), player.breath (coming up) | eating: player.eat
#  while chewing, player.burp at the end | swing: player.swing | bow: player.bow_draw,
#  player.bow_shoot | armour: player.armour (if the use puts it on) | door: use.door_open, then
#  use.door_close | chest: use.chest_open, use.chest_close | furnace: use.furnace_open |
#  inventory: use.inventory_open, use.inventory_close | fires: use.fire, use.torch loops.

chat /time set 6000
chat /weather clear 99999
chat /sounds check

chat /tp 0.5 206 0.5
