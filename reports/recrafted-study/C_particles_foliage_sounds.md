# Recrafted 0.2.1: particles, foliage, sounds (technique notes, own words)

Sources: the unzipped pack (Ronald's copy, outside the repository), Polytone class names. Nothing here is copied; formula fragments are paraphrased. "tick" = 1/20 s. Units: blocks and blocks/tick. Durations of sounds are guesses from file size only (not decoded).

## 0. How the pack is wired (Polytone features it uses)
- **Block modifiers with `particle_emitters`**: per block id, a list of emitters. Each has `chance` (an expression, evaluated per client display tick of that block, same hook as vanilla `animateTick`), `count`, spawn offset `x/y/z`, optional initial velocity `dx/dy/dz`, optional `biomes`, `tick_source` (e.g. block_broken) and expression variables (`TIME`, `RAIN`, `POS_X/Z`, `SKY_LIGHT`, `AGE`, block-state props, `rand()`). Emitters can read **global expressions** (`global.value('recrafted_wind_x')`).
- **Custom particles** (`custom_particles/*.json`): `initializer` (lifetime, size, friction), a `ticker` (either per-field expressions or ONE long script that reads and writes `o.xd()/yd()/zd()`, `o.size()`, `o.age()`, `o.skyLight()`, `o.hasFluid()`, `o.custom(name)` scratch slots, `player.*`, `camera.*`, `global.rain/time`), `rotation_mode` (three expressions for x/y/z rotation of the quad, so sprites tumble in 3D), `has_physics` (vanilla collision), `kill_on_contact`, `random_sprite`, `light_level`, per-biome `colormap` tint, `liquid_affinity`.
- **Particle modifiers** (`hide_vanilla_falling_leaves`): sets life 0 / alpha 0 on vanilla tinted-leaf, cherry and pale-oak falling particles, so only the pack's replace them.
- **A per-player invisible "controller" particle** (`player_particle`, effectively infinite life, `limit 1`, follows the player): carries all `sound_emitters` plus per-frame state (held-item changes, shield use) in `custom` slots. Ambient wind, thunder, foliage-walk and item sounds hang off it. Throttled during the first 1200 ticks after load by a `warmup` counter.
- Polytone also ships a GPU particle system (gpu_particle shaders, heightmap classes). The pack does not use it (no gpu particle files).
- Config toggles: `ambient_particles` (medium cost, balanced+complete), `particle_physics` (medium cost, "complete" preset ONLY), `animated_leaves`/`animated_grass`/`animated_ferns`/`foliage_interaction` (low cost, balanced+), `bushy_leaves` (medium), plus `ambient_sounds`, `block_sounds`, `item_sounds`.

## 1. Global wind (one source shared by shaders and particles)
`assets/recrafted/polytone/global_expressions`:
- `wind_x = -1`, `wind_z = 0`: **fixed prevailing direction, always toward -X (west)**. No per-biome/per-day change. (The GLSL has an optional live-direction uniform; not enabled by these files.)
- `wind_speed` = (0.40 + 0.15 sin(t*0.01309) + 0.10 sin(t*0.004712)) x (1 + clamp(rain,0,1)). Mean 0.40; two slow sines (periods ~480 and ~1333 ticks, 24 s and 67 s) beat so the wind "breathes". Rain doubles it. About 0.15..0.65 dry, up to ~1.3 in storm.
- `water_wind`: same idea around 1.0, smaller amplitude (+-0.09, +-0.06), x(1+rain). Drives water ripples and leaves floating on water.
- `air_state`: packs fog amount and daylight dimness into one integer for shaders (not particles). `tick_gate` flips each game tick (lets shaders do once-per-tick work). `water_phase` accumulates ripple phase (faster in storms). `warmup` counts ticks since load. `fol_trail_dx/dz`: smoothed player-velocity history for grass pushing (see 3).

**Spatial gustiness** is recomputed identically in `wind.glsl` and inside each particle script (no global holds it):
- Shader version: value noise on an 8-block grid; the noise field is **advected downwind at 0.3 blocks/tick**, so gust fronts visibly roll across the land in the wind direction. Sampled with a small time lag, mixed 30% with finer (0.4x scale) flutter noise. Output force f in [-1,1]. Local wind = base direction rotated by up to +-0.45 rad x f, speed = base_speed x max(0, 1 + 0.6 f) x (1 + rain).
- Particle version: two travelling sines over (x,z) (moving with `-x - 0.3 t`) give a gust factor G (amplitude 0.35 dry to 0.75 storm). Wind SP = wind_speed x (0.15 + 0.85 x skyLight/15) (sheltered places feel 15% of it). U = 0.06 SP + 0.18 SP^2 (nonlinear: gusts matter far more than the mean) x G. Three summed sine turbulence waves in x,z,y add a side-gust and an up/down component. Output: target air velocity (wax, way, waz) per particle, in ticks of travel.

## 2. Ambient particles
`particles/assets/recrafted/textures/particle`: 94 json, 54 png. All sprites are tiny: leaves 5x5 px (2 variants per tree via `random_sprite`), petals 2x2 px (2 variants per flower), embers 1x4 px strips animated with `interpolate` (frametime 10), sculk motes 1x8 strip (frametime 10, interpolated), lichen spores 2x2, plus red/green test sprites. Four `leaf_litter_*` 5x5 sprites exist but no particle json references them (unused here).

### 2a. Falling and blown leaves (10 kinds: oak, spruce, birch, jungle, acacia, dark oak, mangrove, cherry, azalea [also flowering], pale oak)
**Spawning** (`block_modifiers/leaves_<tree>.json`, near-identical per tree, two emitters each):
1. *Ambient drop*: chance per display tick of the leaf block ~ 0.0125 x (0.2 + 2w), where w is the same breathing term as wind_speed but WITHOUT rain. At w=0.4 that is ~1.25% per tick; range ~0.4% to 2.1%. Count 1. Position: random x/z over the block, y just under its bottom face (-0.61 from centre). **There is no "air below" test, no biome, season or hour gate, and rain does not change this base rate**; only the wind breathing does. Leaves buried inside a canopy spawn inside neighbour leaf blocks; the non-physics version kills them via `kill_on_contact`, the physics version via its visibility culling.
2. *Gust burst*: same base chance x (1 + 6 x smoothstep(gustLevel, lo, hi)). gustLevel = breathing x (1+rain) x a sharpened local gust factor (the over-1 part counts 2.5x); lo ~0.72, hi ~0.88 dry (both x(1+0.5 rain)), divided by (1+0.6 rain) on the input. So bursts only fire as a gust front passes and reach **7x the base rate** (~9% per tick); in rain the threshold is cleared almost constantly. Position: the downwind face (x = wind_x x 0.6, z = wind_z x 0.6, i.e. 0.6 blocks to the -X side), random y over the block height. These are the "blown off" leaves.
- Vanilla leaf particles are zeroed; only these appear.
- Flowers (poppy, dandelion, cornflower, allium, azure bluet, pink petals, wildflowers) use the same scheme at lower rate: 0.01 x (0.2+2w) x (1 + 1 x smoothstep gust), spawn at y -0.40 (flower base), initial push downwind scaled by wind speed (0.04 x speed) and a small upward kick (dy 0.012). Gust coupling x2, not x7. Petal particle: 512-tick life, size 0.0625 (spawn fade-in over 5 ticks, fade-out last 30), same wind/drag/flutter family, plus a periodic "puff" of extra lift every ~110 ticks (an up-and-over bob after age 75).
- **Player-stirred petals**: the controller particle spawns petals of whatever flower the player is standing in (block_match), while moving and not crouching: chance = clamp(speed x 1.6, 0, 0.25) per tick, count = clamp(speed x 8, 1, 2), at +0.09 above the ground, velocity = half the player's velocity + gaussian jitter 0.04, plus lift 0.015..0.035.

**Motion (ambient version, lifetime 600 ticks = 30 s, size 0.15)**: `has_physics` on, `kill_on_contact` true, so a leaf ends when it touches a block; nothing lands and stays in this mode. Per tick:
- Target velocity = local wind minus a constant sink of 0.095 blocks/tick (~1.9 blocks/s). Velocity is relaxed toward target with kd = min(0.6, 0.10 + 0.5 x |velocity relative to air|): drag grows with relative speed, so leaves hover in the airstream and never overshoot wildly.
- **Flutter**: per-leaf seed in (0,1) gives a flutter period ~34 ticks x (0.8..1.2). A sinusoidal horizontal oscillation (amplitude 0.18 x 0.75..1.25, reduced by `calm` when wind is strong) along a heading = wind direction + random spread (wide in calm air, narrow in strong wind) + slow drift (0.004 rad/tick); a vertical bob at double frequency (slower/faster falling around the sink speed). It is applied as the derivative of the oscillator (add this tick's, subtract last tick's), so it integrates to a clean sine displacement without disturbing the drag.
- **Tumble**: the quad is rotated in 3D from tilt theta and heading. A smooth square wave of the flutter phase (softened edges, softer in storms) swings theta between about +-1.75 rad (+-2.25 in storm), each leaf with its own amplitude wobble, so it flips side to side. Normal built from theta + heading, converted to three rotation angles. When speed falls below ~0.04 the blend `bl` goes to 0 and the leaf is laid flat on whichever face it touched (checks fractional coordinates at 0.1/0.9 of a block to detect floor, wall or ceiling), random yaw from position.
- Size: ramp up over 5 ticks, shrink over the last 20.
- Colour: per-biome colormap png (a `recrafted:<tree>_leaves` map for every biome, default vanilla foliage colour), so leaves match local foliage tint.
- Trees differ only in sprites and colormap; scripts for acacia/jungle, dark oak/mangrove and azalea/cherry/pale oak are byte-identical.
- Storm: larger gust amplitude, updraft term (0.015 x storm^2 x G), narrower flip window, bigger tilt.

### 2b. Particle physics (`particle_physics`, "complete" preset): overrides 17 particles (10 leaves, 7 petals)
Each is a ~70 KB script (a full state machine in the expression language); life 4800 ticks (4 min), NOT killed on contact. From the state-variable names and branches:
- **Visibility culling replaces short life**: every ~10 ticks (staggered by seed) a camera-cone test (yaw, pitch, fov, a distance-scaled cone). Last-seen tick is remembered; a particle unseen for >100 ticks beyond 8 blocks (>600 ticks nearer), or older than 2400 unseen, removes itself. Behind-you leaves vanish; those in view persist.
- **Airborne**: identical flutter to 2a, but wind is recomputed only when moving (speed above ~0.0025) and cached in custom slots (wax/way/waz).
- **Landing**: "grounded" is inferred by comparing the y movement to the expected fall. The 10 ticks after landing run a settling animation: tilt eases to flat over 1..5 ticks (steeper tilt, longer), a small rebound hop (up to 0.15 x |sin tilt|), then a resting offset above the floor (a few hundredths of a block, shrinking over 2400 ticks so leaves slowly compress and layer). Soft surfaces (snow, soul sand, mud) sit 0.125 lower, honey 0.0625. The final orientation is stored (which side faces up, roll) so rest is jitter-free.
- **Resting leaves react to wind**: roughly every 5 ticks a landed leaf compares local wind (its own sky-light shelter) to a per-leaf threshold (~0.5 +-20%, higher in storms) and a cooldown (28..168 ticks, shorter in storm). If exceeded, it **tumbles**: 0..3 half-flips over 7 + max(8 flips, 6) ticks with an eased curve and overshoot, sliding downwind ~0.32 x flips x pi blocks, hopping up to 0.15 blocks at each flip. In heavy storms (rain >0.4, a seeded 40% of leaves, after resting 250..750 ticks, wind strong) a resting leaf is **kicked back into the air** (yd 0.2) and resumes flight.
- **Walls and edges**: detects zero-velocity sliding at a block edge (position on the 1/16 grid within 0.05) and pins the leaf against the wall face for ~40 ticks (rotated to lie against it), ejecting along the wind when a gust arrives.
- **Water**: leaves in a fluid float at the surface (target y = block + ~0.89, a small bob driven by `water_wind`), drift with it. After a random 50..450 ticks (15% never) they sink (die). Player interaction: within 1.2 blocks and moving, floating leaves rock; a moving or diving player pushes a wake: leaves inside a radius that grows with player speed (forward-biased ellipse) are shoved away, and a falling player can sink floaters.
- Within 2 blocks of the player the landed/tumble logic is skipped (vanilla collision takes over).
- Cost: heavy per particle but gated to the complete preset and bounded by culling.

### 2c. Embers, spores, sculk
- **Torch embers** (torch, wall torch, soul, copper): vanilla smoke/flame particles disabled. Three emitters at chance 1 per tick near the flame tip (+0.0625 above centre, +-0.1 sideways; wall torches pick the three matching their facing via a state compare, chance 5). Particle: life 40 ticks, size 0.05 shrinking linearly to 0, self-lit (light 15), swirl radius ~0.07 on a 0.6 rad/tick rotation, rising speed ramping 0.02 x age/20, rolling; animated 1x4 strip (orange, soul blue, copper). Block-broken emitter: 12 vanilla block-chip particles.
- **Glow lichen spores**: chance 0.12 per tick, 2 types; fall at -0.05 while circling (0.03 sin/cos(age/15)), life 200, size follows a parabola (0 -> 0.08 at age ~100 -> 0), light level 7.
- **Sculk motes**: only in the deep_dark biome; chance 0.016 per tick per emitter x 6 emitters on sculk and catalyst: 3 along the top surface (y 1.15), 3 anywhere in a vertical column (-5..+5). Life 200, rise 0.01 x age/20, sideways sine wobble 0.03, light 15, animated 1x8 strips.
- Absent from this pack: fireflies, pollen clouds, drips, splashes, dust, sand/snow blowing, campfire-fire embers. Rain and puddles are shaders (`06_builtin_shaders/precipitation`, `rain_puddles`); `particle_textures` only restyles rain streak, heart, damage and xp orb sprites.

## 3. Foliage animation (Sodium shader + models)
Shared code lives in `animated_foliage_prerequisites` (6.5 KB vertex + 16 KB fragment GLSL + 3 stretched cross models). **It is a fragment-side pixel shift, not vertex displacement.**
- **Model-id tagging through geometry**: block models carry imperceptible vertical/face offsets (multiples of 1/32768 of a block, e.g. codes 38 single plant, 44/58 tall top/bottom, 70 leaf face, 90 leaf plane, 110/130 bush up/down tuft, 157 frosted) so the vertex shader can read "what foliage is this" from a vertex's position alone and pass an id (1..10) to the fragment shader. Avoids needing a block-id attribute. Per-block hashes (position -> 64 seeds) come from the same stage.
- **Plants (grass, fern, tall versions)**: cross quads are stretched (3x width, +6/16 overhang on tops) to leave room. Per fragment the shader maps to a source texel (nearest filter reconstructed from derivatives so pixels stay crisp) and **shifts the source column horizontally by round(amp x heightWeight x wind)**; heightWeight = (rows above anchor / total)^stiffness (0.3 single, 0.7 tall: tips move most), amp = 6 px x sprite width/16 (x1.5 tall), and tip rows droop up to 2.5 px x |wind|. The sprite bends pixel by pixel, stepped, then discards fragments pushed outside. Wind is the shared noise field sampled at the plant centre with time quantised to game ticks (20 Hz stepping), x(1+rain) x exposure gain.
- **Exposure gain**: from the vertex's sky light (5 levels): 0 under cover or indoors, full under open sky; plants flagged "still" never move.
- **Leaf cubes**: faces are not moved; the *texture wraps*: each face is cut into clumps of 4 texels, each clump has a random phase (0..5 ticks) and jitter (+-60%), and the texture is read with an offset of round(4 px x noise x jitter) horizontally (0.7x vertically) using modulo wrap. Leaves shimmer and slide without changing silhouette. One extra sample per fragment. Azalea leaves have their own model overrides (`animated_leaves_azalea`).
- **Bushy leaves** (`bushy_animated_leaves` models + blockstates; `01_textures/bushy_leaves` is just the 73 tuft models and 11 blockstates for all leaf kinds): extra thin up/down plane quads around each leaf cube, whose fragments are cut by a procedural mask (a ragged band 8 texels deep with a peaked profile, per-block random seed) so a fuzzy hull of leaf texture pokes out above and below; the tufts sway with the same wind (lean up to 6 px x 0.65 x wind, height-weighted) and are pre-shaded (0.85 up, 0.5 down). Mid cost (more quads, edge-cut loop).
- **Interaction (`animated_foliage_interaction`)**: plants lean away from the player. The player position (quantised) and crouch/ground flags go in a small uniform, trail velocity history from `fol_trail_*`. Within 1.1 blocks of the player's body (height window 1.9, vertical fade 0.5) plants bend away along player-to-plant direction, up to 10 px (x1.6 tall, x0.45 crouching), with a dead zone near the player. Within 0.45 blocks they are trampled (droop up to 3 px). A "plastic" model: bend peaks are partly retained after you pass (yield 45% of peak, set decays with age^0.5). A trail-segment mode exists but is disabled in shipped constants. `pushonly` model variants react to the player without wind.
- Cost: low (ALU on drawn fragments); bushy tufts add geometry.

## 4. Sounds
Totals: 241 ogg (4.3 MB minecraft namespace, 0.35 MB recrafted), 111 events in `assets/recrafted/sounds.json`; `sound_events.csv` just lists ids (items, ambient.*, block.* and the `.rc_step/.rc_hit/.rc_fall` forwards). `surface_map.json` is not a sound map: it sets a "coverage: render_distance" scan with a `motion_blocking_no_leaves` heightmap (a roof test that ignores leaves) and a few biome fog/sky attributes, i.e. data for shaders/air state.
- **Variant multiplication**: each event lists every file 2..6 times with pitch 0.9 / 1.0 / 1.1 and two volumes (0.2/0.5 ambience, 0.93/1.0 leaves), so 4 files become ~24 playback variants. Block `rc_step` / `rc_hit` / `rc_fall` events are forwards to the main bank with volume 4.5 / 4 / 2 (one bank serves break, place, hit, step, fall).
- **Block sound sets** (25 block_modifier files; 21 ogg in the pack folder): cobblestone+blackstone 4, gilded blackstone 4, magma 4, mossy cobble 4, sandstone 6, stone ores 6 (8 ores), stone bricks 4, mossy bricks 4, cracked bricks 6 (5 kinds), deepslate 6, deepslate bricks/tiles/glazed terracotta/other brick families 4, nether bricks 4, netherrack 6 (plus packed mud, prismarine), bone block 4, clay 6, dirt 4, gravel 6, ice 4 (ice, packed, blue, glowstone), mud 6, podzol 6 (mycelium, dead bush, cactus, azalea), dripstone 6 (volume x4.2), metal grate 4, cake 4, wool 1+, leaves 6 (leaves, moss, path, all small plants, flowers, short grass, fern). Grass block: podzol break/place, leaf step. Sand, snow, cloth, grass step files exist too (sand5, snow1-4, cloth1-4, grass1-6, 10-13 KB, ~0.3-0.6 s). Short one-shots 6-26 KB. No custom rain-on-roof or rain-on-leaves sound; vanilla rain remains.
- **Item sounds**: bow draw in 4 stages fired at `itemUseTicks` 1, 6, 11, 16; hotbar draw / stow when the held item changes (stow when going to empty hand); sword draw for good swords (not wood/stone), shield raise and lower on use start/end; pickup, menu click, snowball throw replaced. Volume 0.22..0.36, pitch random 0.8..0.94.
- **Sound replacement packs** (`sound_replacements/*`): seven sounds.json variants (block, item, menu and combinations, 6-69 KB each) swapping vanilla events.
- **Ambient sounds** (blocks and controller particle; all gated by `ambient_sounds` config; overworld only where noted):
  - `ambient.foliage` (8 files ~26 KB, maybe 2-3 s): emitted by grass/fern/bush and tall plants at chance 0.0005 x SKY_LIGHT per tick; by oak, birch, dark oak leaves at flat 0.002; by acacia/azalea/cherry/jungle/mangrove leaves at 0.0001 x SKY_LIGHT. Volume 0.5; leaf versions at pitch 0.8. Sky-light factor keeps it out of caves. Many eligible blocks around you make it a continuous murmur.
  - `ambient.grasshoppers` (4 files 26-41 KB) on grasses, overworld biome tag, volume 0.15, same chance. `ambient.birds_and_insects` (5 files 48-55 KB, ~4-6 s) wired at chance 0 (disabled), volume 0.075.
  - `ambient.wind` (4 files ~42 KB, ~4-5 s): controller, chance 0.2 x skyLight/15, volume 0.2, overworld. `ambient.wind_storm` (4 files ~44 KB): when rain >= 1, same chance, volume 0.35. `ambient.thunder` (4 files 54-61 KB): chance 0.005 x rain x sky/15, volume 0.35 (rumble layer separate from lightning).
  - `ambient.fire` (5 files ~26 KB): fire and campfire chance 5 (every tick), volume 0.45; all 6 torch kinds chance 2, volume 0.2.
  - Walking in grass: `ambient.soft_rustle` (4 files 18-30 KB) in short grass/fern/bush, `ambient.heavy_rustle` (4 files 27-32 KB) in tall grass/large fern/sunflower; fired once per footstep (derived from walk-animation phase, speed^2 >= 0.01), volumes 2 and 1.5.
  - No biome-specific loops, no cave ambience, no water-specific ambience beyond vanilla.

## 6. What to build ourselves (distilled)
1. One wind vector + slow "breathing" scalar + gust field advected downwind, computed with the same maths in shaders and CPU particles; exposure scaled by sky light.
2. Leaf drops: ~1% per random tick at leaf undersides, plus up-to-7x bursts on the downwind face when a gust front passes; biome-tinted, per-tree sprite.
3. Leaf motion: relax toward (wind - small sink) with drag proportional to relative speed; per-leaf seeded flutter sine added as a derivative; tilt square-wave for tumbling; flat when slow.
4. Landed leaves persist (minutes) with a frustum/distance cull, a settle animation, gust-triggered tumbles, storm lift-offs, water floating.
5. Plants: tip-weighted, texel-snapped sway; leaf cubes: clumped texture-wrap shimmer; bushy leaves: procedural fuzzy hull; player push with partial plastic set.
6. Sounds: duplicate each bank entry across pitch and volume to multiply variants; one bank per surface with forwards for step/hit/fall; ambience chance scaled by sky light; wind and storm layers keyed to weather.
